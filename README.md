# Zariya

**Zariya** is a full-stack travel booking platform inspired by modern accommodation services like Airbnb. This project marks the beginning of my journey into building large-scale, real-world applications using the skills and technologies I have learned throughout my web development learning phase.

## About the Project

After completing a comprehensive learning journey in web development, I am now applying those concepts to build **Zariya**—a standalone, production-oriented project. The goal is to create a scalable and user-friendly platform where users can explore destinations, list properties, and book stays seamlessly.

This repository represents the transition from learning to building, showcasing my ability to implement real-world solutions using modern web technologies.
